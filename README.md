## Description
This website is a basic HTML and Javascript login site with a Python Flask server as the backend. The site checks the users input on both the client and server side. It doesn't store any of the data.

## Files
- `index.html` : Login form and JavaScript validation
- `server.py`: Flask server
- `README.md`: Project description

## How to Run

Install Python 3 with pip. Place `index.html` and `server.py` in the
same folder, then open a terminal in that folder.

Install Flask:

```bash
python -m pip install flask
```

Start the server:

```bash
python server.py
```

Open http://127.0.0.1:5000 in your browser.

Press Ctrl+C in the terminal to stop the server.
